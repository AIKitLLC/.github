# AI Kit

AI Kit builds tools on Cloudflare Workers: edge [APIs](https://developer.mozilla.org/en-US/docs/Glossary/API), agent pipelines and admin templates.

## Featured

- **[nhtsa-edge-api](https://github.com/AIKitLLC/nhtsa-edge-api)**: US public data at the edge: offline [NHTSA](https://www.nhtsa.gov/) [vPIC](https://vpic.nhtsa.dot.gov/) [VIN](https://en.wikipedia.org/wiki/Vehicle_identification_number) decoder, verified against NHTSA's own [SQL](https://developer.mozilla.org/en-US/docs/Glossary/SQL).
- **[cloudflare-admin-template](https://github.com/AIKitLLC/cloudflare-admin-template)**: Cloudflare-native service admin template built with Payload [CMS](https://developer.mozilla.org/en-US/docs/Glossary/CMS) v3, Next.js, Cloudflare D1 ([SQLite](https://www.sqlite.org/about.html)), and R2 storage.
